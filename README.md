# Agency CXO Office

A 15 × 12 m vintage advertising-agency executive suite.

## Current status
The `index.html` file is an **interactive Three.js blockout**, not a photorealistic finished room. It contains room architecture, walnut desk, seating, projector, screen, bookshelf and pinboard using simplified geometry. The next phase is integrating detailed, properly licensed furniture models and PBR textures.

## Preview
After enabling GitHub Pages in Settings → Pages → Deploy from a branch → `main` / `(root)`, open `https://alihashim-work.github.io/agency-cxo-office/`.

## Spline workspace
The connected Spline editor contains a separate editable concept scene called `Agency CXO Office — 15x12m Vintage Suite` (file UUID `d049e5d9-a108-4201-9864-5ae4ffa89daa`). The Three.js website is not automatically synchronized with that Spline scene.

## Cost and repository policy
One public GitHub repository for all versions. Free assets only, with source/license verification before installation. No paid 3D generation.
